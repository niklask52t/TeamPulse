                    TeamPulse
                    
                    WhatsApp Attendance Management
                
                

                    
                    
                    
                

            

        


        
        

            

            

                

                    
Hilfe

                    
                

                

                    

                        
Erste Schritte

                        
Standard-Login: admin / admin — beim ersten Login muss das Passwort geändert werden.

                        
TeamPulse verbindet sich mit einer WAHA-Instanz (WhatsApp HTTP API) und versendet native WhatsApp-Umfragen in eine konfigurierte Gruppe.

                        
Teilnehmer werden automatisch aus der WhatsApp-Gruppe synchronisiert — kein manuelles Anlegen von Kontakten nötig.

                    

                    

                        
Events anlegen

                        
Einmalig: Festes Datum (nur Zukunft). Umfrage wird sofort als "Ausstehend" angelegt.

                        
Wiederkehrend: Wähle einen Wochentag — der Scheduler erstellt jede Woche automatisch eine neue Umfrage.

                        
Uhrzeit: Wann das Event beginnt (z.B. 19:00).

                        
Treffenszeit: Optional — wann sich das Team trifft (z.B. 18:30). Wird in allen Nachrichten zusätzlich angezeigt.

                        
Umfrage senden: Stunden vor Event-Beginn, wann die Umfrage gesendet wird. Standard: 24h.

                        
Abstimmungsfrist: Stunden vor Event-Beginn, wann die Abstimmung schließt UND das Ergebnis automatisch gepostet wird. Standard: 1h.

                    

                    

                        
Umfragen-Lebenszyklus

                        
Jede Umfrage durchläuft vier Phasen:

                        
    
                            
  1. Ausstehend — angelegt, aber noch nicht gesendet
    2. 
                            
  2. Aktiv — WhatsApp-Poll in der Gruppe, Stimmen werden gesammelt
    3. 
                            
  3. Geschlossen — Frist abgelaufen oder manuell geschlossen
    4. 
                            
  4. Archiviert — 24h nach Event-Ende, wandert ins Archiv
    5. 
                        

                        
Automatisches Schließen passiert, sobald die Abstimmungsfrist abläuft. Ergebnisse werden als Text + Bild-Chart in die Gruppe gepostet.

                    

                    

                        
Abstimmen & Antworten

                        
Teilnehmer stimmen direkt in WhatsApp über die native Umfrage ab: Ja / Nein / Vielleicht.

                        
Bei "Nein" oder "Vielleicht": Der Voter bekommt eine private Nachricht und kann innerhalb von 5 Minuten optional einen Grund angeben. Die nächste Nachricht im Chat wird als Begründung gespeichert.

                        
Ergebnisse: Im Dashboard werden alle Antworten mit Namen angezeigt — gruppiert nach Zusagen, Absagen (mit Grund), Vielleicht (mit Grund) und Ausstehend.

                        
Antworten werden alle 15 Sekunden automatisch aktualisiert, wenn ein Poll-Detail geöffnet ist.

                    

                    

                        
Manuelle Aktionen

                        
    
                            
  • Umfrage senden — sendet native WhatsApp-Poll in die Gruppe. Nur bei Status "Ausstehend", einmalig.
    • 
                            
  • Abstimmungs-Erinnerung — Privatnachricht an alle ohne Antwort mit Frist-Uhrzeit. Mehrfach möglich.
    • 
                            
  • Frist verlängern — Deadline um beliebige Minuten verschieben. Löst ggf. erneute Auto-Erinnerung aus.
    • 
                            
  • Umfrage schließen — manuell schließen. Nur bei "Aktiv".
    • 
                            
  • Ergebnis posten — Text + Chart-Bild in die Gruppe. Schließt die Umfrage NICHT. Mehrfach möglich.
    • 
                            
  • Start-Erinnerung — Privatnachricht an alle Zusager ("Event beginnt in 1h"). Mehrfach möglich.
    • 
                        

                    

                    

                        
Automatischer Ablauf

                        
Der Scheduler prüft jede Minute:

                        
    
                            
  1. Ausstehende Umfragen senden — sobald fällig
    2. 
                            
  2. Erinnerung — 60 Min vor Fristende an alle Nicht-Voter (privat)
    3. 
                            
  3. Frist abgelaufen — automatisch schließen
    4. 
                            
  4. Ergebnis posten — sofort nach Schließung
    5. 
                            
  5. Event-Erinnerung — 1h vor Event an alle Zusager (privat)
    6. 
                            
  6. Wiederkehrend — nächste Woche neue Umfrage erstellen
    7. 
                            
  7. Archivieren — 24h nach Event-Ende
    8. 
                        

                    

                    

                        
Statistiken

                        
Der Statistiken-Tab zeigt pro Mitglied: Zusagen, Absagen, Vielleicht, keine Antwort und die Antwortquote in Prozent.

                        
Nur geschlossene Umfragen fließen ein — offene oder ausstehende Umfragen zählen nicht gegen die Quote.

                    

                    

                        
Gruppenbeschreibung

                        
Im Tab Beschreibung wird die WhatsApp-Gruppenbeschreibung verwaltet. Sie wird automatisch bei jeder Änderung aktualisiert (Abstimmung, Schließung, neues Event etc.).

                        
Aufbau:

                        
    
                            
  1. Statische Textblöcke (Position: "Oberhalb")
    2. 
                            
  2. Dynamischer Event-Status: nächstes Event mit allen Zu-/Absagen, Begründungen und ausstehenden Antworten
    3. 
                            
  3. Statische Textblöcke (Position: "Unterhalb")
    4. 
                            
  4. Footer: "Powered by TeamPulse by Niklas Kronig"
    5. 
                        

                        
Textblöcke: Erstelle beliebig viele Blöcke mit Position (oberhalb/unterhalb) und Reihenfolge. Niedrigere Reihenfolge = weiter oben.

                        
Vorschau: Zeigt die aktuelle Beschreibung mit Zeichenzähler (max. 2048 Zeichen).

                        
Voraussetzung: Der WAHA-Bot muss Gruppen-Admin sein, damit die Beschreibung aktualisiert werden kann.

                    

                    

                        
Konfiguration (.env)

                        
WAHA_API_URL — URL der WAHA-Instanz (z.B. http://172.16.80.27:3000)

                        
WAHA_API_KEY — API-Key für WAHA-Authentifizierung

                        
GROUP_CHAT_ID — WhatsApp-Gruppen-ID (Format: 120363xxx@g.us)

                        
SESSION_SECRET — Zufälliger String für Session-Verschlüsselung

                        
DEV_MODE — Bei "true" wird der Gruppen-Tab im Footer sichtbar (zum Nachschlagen von Gruppen-IDs)

                    

                    

                        
WAHA Webhook

                        
In der WAHA-Session muss ein Webhook konfiguriert sein:

                        
URL: http://<TeamPulse-IP>:3000/api/webhooks/waha

                        
Events: message, poll.vote

                        
Ohne korrekten Webhook werden Abstimmungen nicht erkannt. TeamPulse lauscht auf 0.0.0.0, ist also von allen Netzwerk-Interfaces erreichbar.

                    

                    

                        
Fehlerbehebung

                        
Stimmen werden nicht erkannt: Prüfe ob WAHA-Webhooks korrekt konfiguriert sind. Logs: journalctl -u teampulse -f

                        
Gruppen-ID finden: DEV_MODE=true in .env setzen, dann im Footer-Tab "Gruppen" nachschauen.

                        
Erinnerung kam nicht: Erinnerungen werden 60 Min vor Fristende gesendet. Prüfe die Deadline der Umfrage.

                        
Passwort vergessen: Auf dem Server mit Node.js das Passwort zurücksetzen (siehe README).
